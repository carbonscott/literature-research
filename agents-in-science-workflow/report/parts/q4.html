Q4 · Facilities: agents at DOE x-ray and neutron user facilities and national labs

Answer. LLM agents at DOE facilities have moved from documentation assistants and first instrument-control prototypes (2023–24) to supervised control of real beamlines, accelerators and microscopes, peer-reviewed in 2025–26, but steering is still mostly single-campaign demonstrations; deployed systems are mainly knowledge assistants, data-reduction agents and one accelerator control-room framework (Osprey, at the ALS) [@q4_xray_scientist; @q4_vision; @q4_osprey; @q4_apexa; @q4_aps_rag].

Beamline, instrument and accelerator steering

This subsection covers agents that steer beamlines, instruments or accelerators, grouped by lab. Most agents that reduce or analyze data, or answer staff and user questions, are listed under Facility data analysis and knowledge assistants; that is where the SNS agents, and APEXA, APS-RAG and PEAR at the APS, appear.

SLAC

  • SSRL. An LLM agent aligned a single crystal on the BL17-2 six-circle diffractometer. MCP tools wrap SPEC commands; the agent found reference reflections and the orientation matrix. It was developed on a virtual diffractometer, where Claude Sonnet 4 and Gemini 2.5 Flash were benchmarked; Claude Opus 4 ran on the real beamline. For safety, a human relayed each command without modification [@q4_xray_scientist].
  • LCLS. This survey found no public LLM-agent paper on LCLS experiment control. The LCLS items we found are physics-guided Bayesian optimization (not an LLM) that aligned a 12-parameter split-and-delay optic in wave-optics simulations checked against measured data [@q4_lcls_bo], and a computational cognitive model of how operators, analysts and managers interact during LCLS instrument operations, which stresses that LCLS beam time is "extremely valuable and limited" [@q4_lcls_cognitive].
  • Accelerator operations. ChatEED answers operator questions from electronic logbooks and wikis [@q4_chateed].

BNL (NSLS-II, CFN)

  • VISION turns voice or text into Bluesky code at the 11-BM CMS beamline. It ran the first voice-controlled x-ray scattering experiment. Beamline models run locally; cloud GPT-4o serves other functions [@q4_vision].
  • EnvTrace scores control code from more than 30 LLMs against a beamline digital twin, so code can be checked before a live experiment [@q4_envtrace].

Argonne (APS, CNM)

  • CALMS combines retrieval over facility documentation with instrument tool calls [@q4_calms].
  • Human-in-the-loop agents operate an x-ray nanoprobe beamline and a robotic materials station, and improve with feedback [@q4_learn_on_job].
  • Vision-language agents (EAA) automate zone-plate focusing and feature search at an APS imaging beamline [@q4_eaa].
  • On an MCP-compatible atomic layer deposition reactor, only recent models (o1, o3, GPT-5, Claude Opus 4) performed well on process-discovery tasks [@q4_ald_agent].

LBNL (ALS, Molecular Foundry, A-Lab)

  • An agent ran multistage machine-physics experiments on the ALS accelerator. It cut preparation time about 100× within operator safety constraints [@q4_als_agentic].
  • Osprey, the framework behind it, requires human review of a complete plan before any hardware action. It runs in production across hundreds of thousands of ALS control channels [@q4_osprey].
  • Semantic channel finding maps natural-language intent to control signals; proof-of-concepts ran at four facilities [@q4_channel_finding].
  • Lightfall, a beamline control platform with a built-in agent, is in testing at COSMIC-Scattering (preprint) [@q4_lightfall].
  • TEM Agent lets a commercial LLM control microscope subsystems, data management and HPC through MCP [@q4_tem_agent].
  • In the air-free A-Lab, LLM agents proposed 263 of 352 syntheses; researchers designed the rest (preprint) [@q4_alab_gpss].

ORNL (CNMS, SNS)

  • At CNMS, GPT-4 wrote scanning-probe microscope code but struggled with in-depth experiment design [@q4_liu_spm].
  • INTERSECT provides federated microservices for multi-facility autonomous experiments [@q4_intersect_toolkit].

Other accelerators and international facilities

  • Retrieval-augmented e-log search was demonstrated at Fermilab, JLab, LBNL and SLAC [@q4_elog_accel].
  • At DESY, an LLM tuned a simulated accelerator subsystem (an ARES linac beam-tuning task) from an operator prompt, as a proof of principle [@q4_kaiser_sciadv].
  • CSNS (China) runs a Rietveld refinement agent for external users [@q4_rongzai]. We found no comparable deployed system from ESRF, Diamond, European XFEL or PSI. European XFEL has reported two prototypes of an agent that retrieves facility knowledge and writes analysis code in its HPC environment, evaluated with facility experts [@q4_euxfel_agent].

Pre-LLM autonomous-experiment precursors

These closed loops use Bayesian or machine-learning methods, not language models. Most predate the agents above.

  1. Gaussian-process autonomous x-ray scattering, the gpCAM lineage [@q4_kriging_2019].
  2. CAMEO: closed-loop Bayesian active learning at SSRL found a new Ge-Sb-Te phase-change material [@q4_cameo].
  3. ANDiE: autonomous neutron diffraction determined Néel temperatures 5-fold more efficiently [@q4_andie].
  4. Argonne FAST: autonomous scanning microscopy needed under 25% of the sample [@q4_kandel_fast].
  5. Bluesky-hosted agents coordinated multi-beamline measurements at NSLS-II [@q4_maffettone_multimodal; @q4_corrao_multibeamline].
  6. LCLS physics-guided Bayesian optimization of a 12-parameter split-and-delay optic, tested in simulation [@q4_lcls_bo]; ORNL edge-to-exascale steering at SNS, still a proof of concept [@q4_ornl_edge_exascale].

Facility data analysis and knowledge assistants

  • NeuDiff Agent (SNS TOPAZ) goes from raw data to a validated CIF (crystallographic information file). Its safeguards are allowlisted tools, fail-closed gates and full provenance. Processing time fell from 435 min (manual) to 86.5–94.4 min, with no level A or B checkCIF alerts (the most serious validation warnings) [@q4_neudiff].
  • ORNL neutron small-angle and diffraction tools. SasAgent drives SasView [@q4_sasagent]. EQSANS-CLI lets an external agent run reductions from Slack (preprint) [@q4_eqsans_cli]. VULCAN's reduction pipeline was written with an AI coding agent [@q4_vulcan_reduction].
  • APEXA (APS) is a deployed calibration and integration agent with 61 tools (preprint). A frontier model fabricated a calibration report for commands that never ran. Against a simulated IOC, motor-control violations were 0/200 with its deterministic guard and 15/200 with a safety prompt alone [@q4_apexa].
  • Other analysis agents. PEAR uses multiple agents for ptychography [@q4_pear]. Rongzai (CSNS) runs GSAS-II from a natural-language task to a report [@q4_rongzai].
  • Knowledge and user-program assistants. ESAC is a chatbot for visiting EQ-SANS users [@q4_esac]. APS-RAG, deployed for APS staff, reached 70.3% strict recall versus 63.8% for a BM25 baseline [@q4_aps_rag]. For SNS proposals, LLM rankings correlated with human rankings at ρ≈0.2–0.8, at over 100× lower cost [@q4_proposal_llm].

DOE programs and policy

  • Genesis Mission. The executive order of Nov 24, 2025 creates a platform that explicitly includes "AI agents" and autonomous experimentation. It sets milestones at 60, 90, 120, 240 and 270 days; the 240-day step reviews robotic laboratories. It requires classification, cybersecurity and export-control compliance [@whitehouse2025genesis].
  • Genesis follow-up. DOE named 26 challenges, including "Enhancing Particle Accelerators for Discovery" and "Achieving AI-Driven Autonomous Laboratories" [@q4_genesis_challenges]. The autonomous-labs challenge names DOE user facilities and national laboratories as its "nucleus" [@q4_genesis_autolabs]. DOE signed agreements with 24 organizations, among them Anthropic, AWS, Google, NVIDIA and OpenAI [@q4_genesis_mous]. In July 2026 the White House announced more than $5B in federal commitments from more than 15 agencies, and DOE selected 278 projects [@q4_genesis_5b]. DOE also announced more than $800M from partners [@q4_genesis_800m]. An Office of Science advisory subcommittee's high-performance-magnets milestones include connecting autonomous labs to user facilities [@q4_scac_genesis].
  • American Science Cloud (AmSC). Public Law 119-21, Sec. 50404 ("Transformational artificial intelligence models") defines the American Science Cloud and appropriates $150M, through Sept 30, 2026, for curating DOE data and seeding science AI models to be shared through it [@q4_pl119_21]. An ASCR lab call builds on IRI and includes API access to user facilities and instruments [@q4_amsc_lab25_3555]. AmSC aims to unify access to the 17 DOE labs and 28 user facilities that ESnet already links, adding a common identity layer and shared service interfaces [@q4_lbnl_amsc]. The multi-lab SYNAPS-I project (LBNL-led, with Argonne, BNL, ORNL and SLAC) targets real-time analysis at light and neutron sources [@q4_lbnl_amsc; @q4_synaps_release].
  • Funding calls. A DOE package of more than $320M includes 14 robotics and autonomous-experiment projects [@q4_doe_ai_investments]. A robotics and automation testbed call is about $30M [@q4_lab26_3601].
  • FASST. DOE released a roadmap in 2024 for FASST (Frontiers in Artificial Intelligence for Science, Security and Technology) [@q4_fasst_roadmap]. Our inference, not a DOE statement: Genesis now plays FASST's umbrella role.
  • 1,000 Scientist AI Jam (Feb 28, 2025). More than 1,400 scientists at nine labs took part; SLAC was not one of them [@q4_llnl_aijam].
  • Lab–company partnerships. OpenAI models run on LANL's Venado supercomputer [@q4_lanl_openai; @q4_nnsa_venado]. Anthropic's DOE partnership plans MCP servers that connect Claude to scientific instruments [@q4_anthropic_doe]. DOE announced NVIDIA-based Solstice and Equinox at Argonne [@q4_doe_nvidia_oracle] and AMD-based Lux and Discovery at ORNL [@q4_doe_amd_lux].
  • Integrated Research Infrastructure (IRI). A 2023 blueprint lays out how to link experimental facilities, computing and data [@q4_iri_aba].

Integration points

  • Instrument control. Agents reach hardware through SPEC [@q4_xray_scientist], Bluesky [@q4_vision; @q4_bluesky] and control-system channels [@q4_osprey].
  • Data and workflows. A Tiled, Prefect and gpCAM workflow ran at both ALS and PETRA III with minimal facility-specific changes [@q4_als_petra].
  • Tool layer. MCP is a common way to expose instruments and data to agents [@q4_xray_scientist; @q4_eaa; @q4_tem_agent; @q4_aps_rag].
  • Computing. Agents can be served on leadership-class HPC [@q4_agentic_hpc]; a planned AmSC API, built on the IRI framework, is to give code-level access to user facilities and instruments [@q4_amsc_lab25_3555].

Facility-specific constraints

  • Beamtime. LCLS beam time is "extremely valuable and limited" [@q4_lcls_cognitive]. The SSRL team developed the workflow in simulation and deployed it on the beamline with only interface-level changes [@q4_xray_scientist].
  • Safety. Current safeguards sit outside the model: human relay [@q4_xray_scientist], plan review [@q4_osprey], allowlisted tools [@q4_neudiff], deterministic guards [@q4_apexa], or a digital-twin check before execution [@q4_envtrace].
  • User turnover. Visiting users need guidance [@q4_esac], and agents must work zero-shot, without long training periods [@q4_base_scale].
  • Security and data policy. Genesis mandates classification, cybersecurity and export-control compliance [@whitehouse2025genesis]. VISION runs its beamline-control models on a local GPU server and sends only chatbot and refinement tasks to cloud GPT-4o [@q4_vision].
  • Verification. Checking results, not generating ideas, is now the bottleneck [@q4_trust_roadmap].
